# ASOBI — status-service

Esta pasta tem o serviço que confere, a cada 5 minutos, se a loja e os outros serviços estão no ar
e avisa os admins por e-mail quando algo cai (e quando volta).

A explicação completa (como rodar, configurações e como colocar no ar) está em
[docs/status-service.md](../docs/status-service.md).
